Velocity Radar is a program (main.ts, Node 22, stdlib only) that reads a sealed DeFiLlama protocol snapshot and ranks every rankable pre-token protocol by velocity — the dollars moving into it this week, how young it still is, and how big it already is — writing a ranked 198-row board (board.json), a static paper-light dashboard (dashboard/, no network), and a dossier. Watchlist 40/40 covered; top implied value $1.51B (Sentora Curator); fastest money this week $142.8M into Shift DeFi. Each row carries a 0–100 heat score, a sensitivity trio (implied value at −10%, as reported, and +25% for the week), and a seven-step farm plan with costs and times.

## Run it

```sh
node main.ts
```
